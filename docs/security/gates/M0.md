# M0 Security Gate — Base

PRD_go.md section 10.1, "M0 — Base": twelve verifiable checklist items.
Per PRD section 10: "La puerta se verifica con evidencia (resultado de CI,
informe, captura, entrada en el runbook), no con una afirmación." — the
gate is verified with evidence, never a bare assertion.

Split into two checkpoints so a green CI run is never mistaken for a
closed milestone (`openspec/changes/m0-foundation/tasks.md`, Phase 13/14):

- **Checkpoint A** — closeable entirely from this repository (code, tests,
  CI runs, documents). No deployed server is required.
- **Checkpoint B** — requires the target server deployed under Portainer.
  Tracked separately; **not started** as of this document.

Each row cites the spec requirement that carries the acceptance scenarios,
rather than restating the checklist, so the two cannot drift
(`openspec/config.yaml` rule: "the specs already cite every gate item by
number").

### Task 11.11 — the deliberately-failing probe

A live GitHub Actions run of a probe PR could not be produced from this
offline batch (no `git push`/PR creation available in this session). The
equivalent, and stronger, evidence: running every `security.yml` scanner
locally against this repository's **real** dependency tree, before any fix,
genuinely failed —

```
$ cd api && ~/go/bin/govulncheck ./...
Vulnerability #1: GO-2026-6253
    moby/go-archive: Crafted tar archive can write outside the extraction
    directory in github.com/moby/go-archive
    Found in: github.com/moby/go-archive@v0.2.0
    Fixed in: github.com/moby/go-archive@v0.3.0
Your code is affected by 1 vulnerability from 1 module.
```

reached through `internal/testhelpers` (a real, exploitable transitive
dependency, not a synthetic probe), which is exactly the failure
`security.yml`'s `govulncheck` job is wired to block on. This batch fixed it
(`go get github.com/moby/go-archive@v0.3.0`) and re-ran clean, demonstrating
the full red -> green cycle the gate is meant to enforce. `security.yml`
itself has not yet executed on GitHub's infrastructure — that first real run
is Checkpoint B/deployment-adjacent evidence, not fabricated here.
